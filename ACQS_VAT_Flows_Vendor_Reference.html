① Tax Invoice Generation Flow
ใบนำฝากเงิน / ใบกำกับภาษี · Tax Document · Must submit to ETER
Signature rule (TaxLawX confirmed): No physical wet signature or bank stamp required. Electronic Signature embedded by ETER satisfies มาตรา 105 ทวิ + ข้อ 4 ประกาศฯ.
Template parity: Auto-generate and Manual Data Entry are legally identical — both must use the same ETER template (Merchant Report Scenario V2.0_TLX220726.xlsx).
Processing Steps
  1. EOD settlement batch triggers document generation
  2. Read MERCHANT_TAX_PROFILE: MDR rate, VAT flag, WHT_RATE, WHT_SUBMISSION_METHOD
  3. Calculate: MDR fee = Sale × MDR rate
  4. Calculate: VAT = MDR × 7%
  5. Calculate: WHT amount = MDR × WHT_RATE (dynamic — NOT hardcoded)
    e-WHT path: 1% (Jan 2026–Dec 2027 per ครม. 16 Jun 2026)
  6. Select WHT text template:
    — E_WHT: Template A (past-tense "เรียบร้อยแล้ว")
    — STANDARD: Template B ("ภายในวันที่ 15 ของเดือนถัดไป")
  7. Generate Tax Invoice with ETER mandatory footer statement NEW
  8. Submit to ETER → receive registration number
  9. Status → POSTED only after ETER confirmation
  10. Email PDF to merchant registered email

② Credit Note Generation Flow CRITICAL UPDATES
ใบลดหนี้ · Tax Document · Must submit to ETER · COM_VAT_RETURN = Y
CRITICAL — Amount logic changed: Credit Note must show DELTA (reduction) amount only — NOT the full original invoice amount. Previous ETER behaviour (full cancellation + new invoice with no reference) was non-compliant.
Processing Steps
  1. Detect refund with COM_VAT_RETURN = Y
  2. Set original Tax Invoice status → CANCELLED
  3. Check เหตุผลในการลดหนี้ field — BLOCK if empty NEW
  4. Calculate credit amount = DELTA (reduction amount only)
    e.g. original MDR = 100 THB, refund = 40 THB → Credit Note = 40 THB
  5. Calculate remaining = Original − Delta
    e.g. 60 THB → goes on new Tax Invoice
  6. Validate timing: Credit Note date must be within same or following VAT month as reason (มาตรา 86/10) NEW
  7. Generate Credit Note with ETER footer statement
  8. Generate new corrected Tax Invoice referencing original
  9. Submit both Credit Note + new Tax Invoice to ETER
  10. Status → POSTED only after BOTH ETER registrations confirmed
  11. Email both documents to merchant

③ Debit Note Generation Flow UPDATED
ใบแจ้งหักบัญชี · NOT a tax document · NOT submitted to ETER · COM_VAT_RETURN = N
NOT a tax document. No VAT. No ETER. No digital signature requirement. Status = POSTED immediately. No legal minimum content requirement per Revenue Code.
Processing Steps
  1. Detect refund with COM_VAT_RETURN = N
  2. Generate Debit Note: number format DR + 10-digit sequential
  3. Document name = "ใบแจ้งหักบัญชี" UPDATED
    Old name "ใบแจ้งหนี้หักบัญชี" removed
  4. Set VAT/Tax field = 0.00 ALWAYS UPDATED
    Never calculate VAT on Debit Note
  5. Populate Account Debit Statement template NEW
  6. Status → POSTED immediately (no ETER wait)
  7. Email PDF to merchant
  8. Do NOT submit to ETER
